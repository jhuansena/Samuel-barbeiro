# Barbearia Samuel Gomes — site

Como abrir no VS Code:
1. Abra a pasta no VS Code (Arquivo > Abrir Pasta).
2. Instale a extensão "Live Server" e clique em "Go Live" (ou abra o index.html no navegador).

Estrutura:
- index.html — página
- css/style.css — estilos
- img/ — fotos

Para trocar uma foto, substitua o arquivo em img/ mantendo o mesmo nome.
Link de agendamento: procure por "inbarberapp" no index.html.
